# 字库更新指南

本文说明如何更新应用的汉字数据(新增汉字、修正字形、刷新词库/释义)。

## 数据流总览

```
Make Me a Hanzi (graphics.txt + dictionary.txt)
        │  tools/build_chars_dictionary.py
        ▼
assets/data/chars_3500.json          ← 中间产物,不打包进应用
        │
        ├─ tools/build_stroke_names.py      ← cnchar-order 笔顺名称
        │       └→ assets/data/stroke_names.json
        ├─ tools/build_words_dictionary.py  ← CC-CEDICT 组词+拼音
        │       └→ assets/data/words.json
        └─ tools/build_definitions_zh.py    ← 新华字典中文释义
                └→ assets/data/definitions_zh.json

chars_3500.json + stroke_names.json
        │  tools/split_chars_data.py   ← ⚠️ 必须最后跑
        ▼
assets/data/chars_index.json   (~435KB,首页/搜索/筛选,启动即加载)
assets/data/shards/shard_NNN.json (38 片,详情页按需加载)
```

> 应用运行时只加载 `chars_index.json`、`shards/` 与两个详情页数据集;
> `chars_3500.json` / `stroke_names.json` 仅是管线中间产物,保留在仓库里便于重建。

## 标准更新流程

### ① 更新源头字库

`build_chars_dictionary.py` 支持传 URL 或本地文件路径:

```bash
python3 tools/build_chars_dictionary.py \
  --graphics https://raw.githubusercontent.com/skishore/makemeahanzi/master/graphics.txt \
  --dictionary https://raw.githubusercontent.com/skishore/makemeahanzi/master/dictionary.txt
```

产出约 9600 个 CJK 汉字条目(含笔画轮廓 SVG 与中轴线)。

### ② 依次重跑下游工具(顺序固定)

```bash
python3 tools/build_stroke_names.py      # 笔顺名称,覆盖 ~6800 字
python3 tools/build_words_dictionary.py  # 组词+带调拼音,~6100 字(儿童内容过滤)
python3 tools/build_definitions_zh.py    # 中文释义,~7400 字
python3 tools/split_chars_data.py        # ⚠️ 拆出 index + shards,漏跑则改动不生效
```

首次运行会自动下载源数据到 `tools/cache/`(已加入 .gitignore):
`stroke-order-jian.json`(cnchar)、`cedict.txt.gz`(MDBG)、`xinhua_word.json`(pwxcoo)。
也可提前手动放入缓存目录以离线执行。

### ③ 验证

```bash
flutter analyze
flutter test
```

相关测试会自动把关:

| 测试 | 校验内容 |
|------|---------|
| `dictionary_data_validation_test.dart` | 全部分片条目结构:笔数一致、order 连续、SVG/中线非空 |
| `reference_assets_validation_test.dart` | words.json / definitions_zh.json 覆盖率与格式契约 |
| `stroke_classifier_golden_test.dart` | 32 个样例字的官方笔顺名称回归 |
| `stroke_reveal_coverage_test.dart` | 揭示笔刷对真实字形边界的覆盖率 |

### ④ 本地验证效果

```bash
flutter run -d chrome --web-port 8765
```

数据有变时浏览器强刷:`Cmd + Shift + R`;异常时 `flutter clean && flutter pub get` 后重跑。

## 常见场景

### 场景 A:上游 MakeMeAhanzi 更新了字形/新增汉字

走上面完整流程即可(全量重建)。
可先在上游仓库搜索目标字确认是否存在:

- 存在 → 全量重建后该字的笔画动画、笔顺名自动就绪
- 不存在 → 目前无法自动生成(SVG 路径需手造),查询时会显示"未找到该汉字"

### 场景 B:只刷新组词或释义(字形不变)

跳过 ①,从对应工具开始跑,最后必须重跑 `split_chars_data.py`
(它会把 strokeNames 合入分片;仅刷组词/释义时可跳过 split,但跑了无害)。

```bash
python3 tools/build_words_dictionary.py   # 只更新组词
flutter test test/reference_assets_validation_test.dart
```

### 场景 C:调整每个字的组词数量上限

```bash
python3 tools/build_words_dictionary.py --max 12
```

## 能力覆盖与降级行为

各数据集覆盖范围不同,**缺失时应用自动降级,不会报错**:

| 数据 | 来源 | 覆盖 | 缺失时的表现 |
|------|------|------|-------------|
| 字形/笔顺动画 | Make Me a Hanzi | ~9600 字 | 显示"未找到该汉字" |
| 笔画名称 | cnchar-order | ~6800 字 | 几何分类器推断(`StrokeClassifier`) |
| 组词+拼音 | CC-CEDICT | ~6100 字 | "词库建设中,敬请期待"占位 |
| 中文释义 | 新华字典(pwxcoo) | ~7400 字 | 回退显示英文释义(examples 字段) |
